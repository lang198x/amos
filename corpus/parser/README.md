# Perfect 10 parser fixture

`perfect-ten.amos.txt` retains lines 128–132 of the maintained Bank or Risk
listing in `../highlighting/bank-or-risk.amos.txt`. The source keeps its upstream
MIT licence; see `../LICENSE`. The fragment tests host parsing only. It does not
claim that all game forms parse. Separate [native trials](../editions/perfect-ten/README.md)
cover this block in three exact installations.
