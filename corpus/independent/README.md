# Independent highlighting inputs

These files predate this grammar work and retain exact upstream ASCII bytes.
sources.json pins the repository revisions, paths, hashes, licence notices and
independently reviewed scope ranges. Both upstream notices are retained here.

- Asciify is a real AMOS file-conversion accessory (39 lines), testing nested
  control flow, strings, directory queries and Editor/equate calls.
- Tiny_Shell_Dbl is the original compiler's Interface panel text (72 lines),
  testing compact postfix expressions, significant capitals, button routines and
  messages. The retained ranges cover command heads and selected expression forms;
  they are not a complete token inventory or proof of stack/GUI correctness.
- Numbers (77 lines) is an independent lister regression fixture. It exercises
  scientific notation, spaced exponents and separate negative signs. It is not
  presented as a working application or a native import trial.

The tests preserve every source character, inspect reviewed spans in both themes,
and render through both existing consumers. Asciify is checked in both BASIC
modes; Tiny_Shell_Dbl uses standalone Interface. These are two small programs,
not a representative survey of all AMOS software. No listing is executed, and no
native files, assets, runtime media or private data are included.
