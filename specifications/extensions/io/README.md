# I/O documentary inventory

This inventory records 18 serial and ten parallel headings from Professional
§§10.4–10.5. Both chapters are included in the 622-entry BASIC lexical inventory. No native release is qualified.

`source.json` binds the pinned manual and boundary excerpts. `original-source.json`
retains a complete token-table excerpt and narrow dispatch/component evidence from
the official source revision, with its MIT licence. Serial Buf and the serial/
printer/parallel grouping are source-resolved, without proving default installation.

Each entry has an exact heading/page citation, documented role and fresh lexical
example. Examples have not been executed. Serial Buf follows the heading and
original token table; its conflicting Serial Buffer signature is retained.
`questions.json` distinguishes source-resolved spelling/grouping from unresolved
Serial X semantics and the Serial Base source/manual arity conflict.

Printer (§10.3), Music (§8) and picture compaction (§6.2) are related provenance
precedents, not evidence of default I/O installation or edition compatibility.
See the [boundary review](../../../docs/io-extension-boundary.md) for the adopted
lexical treatment and alternatives. Native device access, buffer/pointer safety,
protocols, OS drivers, character data and transfer timing are outside this review.
