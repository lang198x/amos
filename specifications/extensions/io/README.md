# I/O documentary inventory

This review records 18 serial and ten parallel headings from Professional
§§10.4–10.5. It adds no highlighting, parser support, native qualification or new
editor mode. The BASIC inventory remains 594 chapter entries.

`source.json` binds the pinned manual and retained boundary excerpts. Serial is
explicitly attributed to the I/O Extension; the adjacent parallel chapter does
not explicitly identify its implementation component. Grouping these files here
does not settle that ownership. No releases are qualified.

Each entry has an exact heading/page citation, documented role and fresh lexical
example. Examples have not been executed. Serial Buf deliberately follows the
heading while retaining the conflicting Serial Buffer signature and an unresolved
spelling status. Neither form is approved for a new highlighting rule yet.
`questions.json` keeps unresolved spelling, handshake semantics and parallel
component ownership separate from the documentary facts.

Printer (§10.3), Music (§8) and picture compaction (§6.2) are related provenance
precedents, not evidence of default I/O installation or edition compatibility.
See the [boundary review](../../../docs/io-extension-boundary.md) for the proposed
lexical treatment and alternatives. Native device access, buffer/pointer safety,
protocols, OS drivers, character data and transfer timing are outside this review.
