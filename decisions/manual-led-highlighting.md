# Use manual inventories to expand highlighting

Adopted 20 October 2026 after approval of the manual-led core sweep.

Use primary-manual inventories to choose and assess vocabulary coverage rather
than allowing one game to define the language. Begin with the Professional User
Guide's chapters 5.1–5.5: basics, strings, maths, control structures and procedures.
Retain chapter/page provenance, grouped forms, typed variants and fresh examples.
Use independent mixed listings and the existing full-game corpus for regression
checks. Keep vocabulary data and implementation files small and focused.

Coverage identifies its documentary product and source. Professional manual
facts do not silently qualify Creator, Easy, every Professional release or an
extension. Record discrepancies rather than converting suspect prose into
semantics. Original runtime acceptance remains a separate kind of evidence.

TextMate stays canonical for lexical scopes, with an exact synchronised editor
copy. This adds no grammar-generation framework, parser implementation or
dependency. Declaration names can be recognised lexically; resolution and types
still belong to the canonical analysis implementation when developed.

The Marketplace preview remains private. A completed chapter inventory is not
automatic public-release approval. Reconsult this decision before claiming
whole-language coverage or inferring an edition/extension profile from the union
of highlighted words.
