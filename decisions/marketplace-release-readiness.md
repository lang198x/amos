# Keep the Marketplace preview private until coverage is ready

Adopted 20 October 2026 after review of the 0.1.1 submission.

The Marketplace extension stays private until its highlighting has a reasonable
degree of coverage. Publisher setup, an accepted upload, Microsoft validation,
a working installation and an approved icon do not establish release readiness.
Do not make the listing public as the automatic next step after validation.

Agree the coverage scope and review its evidence before a public release. The
current physical-line-head audit is a baseline, not a coverage percentage or a
release gate by itself. Highlighting coverage and parser coverage remain separate;
this decision does not commission a full parser, compiler or LSP implementation.

Steve approved the next bounded milestone: the complete pinned Bank or Risk listing.
The scope is to
inventory full command forms and functions in expressions, check them against
primary manuals, and verify mixed case, boundaries, identifiers, strings and
comments. Control/data, display and sound/input groups can be delivered in small
changes. Completion is a coverage milestone, not an adopted definition of
sufficient whole-language coverage or automatic public-release approval.

Existing public GitHub preview downloads and the npm grammar remain available.
This decision restricts public Marketplace release; it does not retract those
previously authorised previews.

Reconsult before uploading an extension with public gallery flags, changing
Marketplace availability, or claiming the editor is ready for public discovery.

## Public preview 0.3.0 approval

On 21 October 2026, after the bounded highlighting readiness review and verified
0.3.0 draft preparation, Steve instructed: “Let's publish it all. And set up
trusted publishing”. This authorizes public Marketplace availability of the
scoped 0.3.0 preview, alongside the GitHub prerelease and npm next publication.
It supersedes the private-only restriction above for this reviewed preview.

The evidence is docs/highlighting-readiness.md and
docs/releases/0.3.0-evidence.json. This remains Professional-based lexical
highlighting with optional 3D and standalone AMAL/Interface modes. Creator, Easy,
other revisions, parser completeness and native execution remain unqualified.
Future scope claims and stable releases still require their own review.
