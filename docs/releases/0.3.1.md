# AMOS editor preview 0.3.1

This editor-only patch makes the reviewed highlighting preview discoverable on
the Visual Studio Marketplace. It adds the Public gallery flag while retaining
the Preview label and prerelease-channel property. The four grammar files are
identical to 0.3.0. The README now describes Marketplace installation.

Install **AMOS — Lang198x** (`lang198x.lang198x-amos`) and select its pre-release
version, or download the VSIX from this GitHub prerelease and use
**Extensions: Install from VSIX**. The npm highlighting package remains 0.3.0
under next; the Rust parser remains 0.1.0. No language behaviour changes.

The [0.3.0 scope and limits](0.3.0.md) apply: Professional-based lexical
highlighting, optional AMOS 3D and standalone AMAL/Interface modes. Creator,
Easy and other revisions remain unqualified. No compiler, native decoder or
language server is included.

The earlier 0.3.0 files retain their original bytes. This patch is a distinct
artifact because that VSIX was deliberately packaged without public visibility.
