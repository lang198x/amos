# Highlighting preview 0.2.0

This preview brings the expanded highlighting to npm and the downloadable VS
Code extension. Both packages use 0.2.0; the Rust kit remains 0.1.0. Install npm
with `npm install @lang198x/amos@next` or pin `@lang198x/amos@0.2.0`.

Download the VSIX from the [GitHub prerelease](https://github.com/lang198x/amos/releases/tag/v0.2.0)
and use **Extensions: Install from VSIX**. Marketplace availability remains private;
this release does not update the Marketplace submission.

The default AMOS mode includes the complete pinned Bank or Risk highlighting
milestone and 452 inventoried Professional BASIC entries. The opt-in **AMOS +
AMOS 3D** mode adds 59 extension records; choose `amos-3d` in web consumers or
VS Code's language selector. Existing default imports and `.amos.txt` associations
keep their behaviour. TextMate JSON and TypeScript declarations are included.

Fourteen embedded menu records and 36 AMAL records remain documentary inventories;
their string contents are not separately highlighted. General file-channel I/O,
broader sound facilities, Interface and edition/release qualification remain
further work. Colour does not establish valid arguments or native acceptance.
There is no compiler, LSP, native `.AMOS` codec or expanded Rust parser.

Verification includes all inventory/package checks, both existing highlighting
consumer installations in light/dark themes, exact packaged grammar/icon checks,
extracted npm imports/types and an isolated VS Code installation. The download
includes SHA-256 checksums for both packages. Installed native visual review and
original AMOS execution are separate from these package checks.
